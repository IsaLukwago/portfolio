# Isa Lukwago — Personal Developer Portfolio

A clean, responsive personal portfolio website built from scratch to document my Computer Science learning journey, foundational projects, and technical skills.

🌐 **Live Website:** [https://netlify.app](https://isalukwago.netlify.app/)

---

## 🛠️ Technologies Used
* **HTML5:** Semantic structure (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) for accessibility and SEO.
* **CSS3:** Modular styling with CSS custom properties (variables), Flexbox, and responsive CSS Grid.
* **JavaScript (ES6+):** DOM manipulation for dynamic footer year updates and one-click email clipboard copying.
* **Git & GitHub:** Version control and source code hosting.
* **Netlify:** Continuous deployment (CI/CD) linked directly to the `main` branch.

---

## 📂 Project Structure
```text
portfolio/
```
